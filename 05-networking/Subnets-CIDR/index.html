Sección 02

Network vs Host

La frontera variable que separa la red de los dispositivos individuales

192.168.1.10 / 24
NETWORK (24 Bits / 3 Octetos)
HOST (8 Bits)

La parte de NETWORK identifica a la autopista principal. La parte de HOST identifica la casa específica en esa autopista.

/ 8

NETWORK: 192
HOST: .168.1.10

Red gigante, pocos bloques.

/ 16

NETWORK: 192.168
HOST: .1.10

Red mediana equilibrada.

/ 24

NETWORK: 192.168.1
HOST: .10

Red pequeña (256 direcciones).

Sección 03

Clases Históricas de IPv4 (Classful)

El modelo rígido tradicional de direccionamiento antes de CIDR

Clase Primer Octeto Prefijo Histórico Bits Iniciales Propósito Histórico
Clase A 1 – 126 /8 0xxxxxxx Redes muy grandes (16M hosts)
Clase B 128 – 191 /16 10xxxxxx Redes medianas (65k hosts)
Clase C 192 – 223 /24 110xxxxx Redes pequeñas (254 hosts)
Clase D 224 – 239 — 1110xxxx Tráfico Multicast
Clase E 240 – 255 — 1111xxxx Experimental / Reservado
💡 Contexto de Transición: El modelo Classful provocó un desperdicio masivo de direcciones IP (Ejemplo: si necesitabas 300 IPs, debías usar Clase B /16 con 65,536 IPs, desperdiciando >64,000).
Sección 03 — Evolución

Evolución: Classful → CIDR

Classless Inter-Domain Routing (Prefijos de Longitud Variable)

🏛️ CLASSFUL (Histórico)

Tamaños fijos e inflexibles:

Clase A: Solo /8

Clase B: Solo /16

Clase C: Solo /24

Resultado: Ineficiencia y agotamiento prematuro de direcciones IPv4.

⚡ CIDR (Modelo Moderno)

Cualquier prefijo dinámico entre /8 y /32:

Flexibilidad: /17, /22, /25, /26, /27, /28...

Resultado: Asignación exacta del tamaño necesario según la demanda real.

⚠️ Regla Importante de Examen

Las clases A/B/C son un histórico. AWS VPC utiliza exclusivamente CIDR (Classless) para definir el direccionamiento de redes y subredes.

Sección 04 — Matemática Intuitiva

¿Cómo se calcula el tamaño de red?

Construyendo la intuición de la potencia de 2 antes de la fórmula

🔢 Exponentes de Bits de Host
  • 8 bits de host: 2^8 = 256 combinaciones totales
  • 7 bits de host: 2^7 = 128 combinaciones totales
  • 6 bits de host: 2^6 = 64 combinaciones totales
  • 5 bits de host: 2^5 = 32 combinaciones totales
⚠️ Diferencia Crítica: Tradicional vs AWS

IPv4 Tradicional: Se restan 2 IPs (Network Address y Broadcast Address).

AWS VPC Subnet: AWS reserva 5 direcciones IP en cada subred (Red, Router VPC, DNS, Uso futuro de AWS, y Broadcast).

¡Nunca uses la fórmula 2^n - 2 directamente para calcular disponibilidad en subnets AWS!

Sección 07 & 08

Rangos Privados IPv4 (RFC 1918) y AWS VPC

Las direcciones no enrutables en Internet utilizadas para construir nubes privadas

🔒 Rangos Privados Estándar
  • 10.0.0.0 / 8 (10.0.0.0 – 10.255.255.255)
  • 172.16.0.0 / 12 (172.16.0.0 – 172.31.255.255)
  • 192.168.0.0 / 16 (192.168.0.0 – 192.168.255.255)
☁️ Conexión con Amazon VPC

Al crear una VPC en AWS, le asignas un bloque CIDR privado (Ejemplo: 10.0.0.0/16).

Posteriormente, creas **Subnets** dentro de la VPC dividiendo ese bloque principal en rangos más pequeños (Ejemplo: 10.0.1.0/24).

Sección 09

Pensar en Crecimiento y Evitar Solapamientos

Principios clave de diseño de redes híbridas y en la nube

⚠️ Error Común: Solapamiento (Overlap)

Si la VPC de AWS usa 192.168.1.0/24 y la red local (On-Premises) de la empresa usa 192.168.1.0/24, NO se podrán conectar mediante VPN o Direct Connect debido al conflicto de rutas.

🌱 Planificación para Crecimiento

Asegúrate de reservar bloques libres en la VPC (Ej. usar /16 en la VPC y asignar subnets /24 dejando espacio libre entre ellas). Rediseñar una VPC activa sin espacio es un proceso altamente complejo.

Sección 10

"Trampas Frecuentes" en el Examen

Aclarando malentendidos conceptuales para asegurar tu certificación

❌ Error 1: Pensar que /24 significa "24 direcciones IP".
✓ Corrección: /24 significa que 24 bits pertenecen a la Red (quedan 256 direcciones IP).
❌ Error 2: Usar la fórmula 2^n - 2 para calcular disponibles en AWS.
✓ Corrección: AWS siempre reserva 5 direcciones por subnet (2^n - 5).
❌ Error 3: Pensar que las Clases A/B/C rigen AWS VPC.
✓ Corrección: AWS utiliza estrictamente notación CIDR sin clases.
❌ Error 4: Crear subnets con bloques fuera del CIDR de la VPC.
✓ Corrección: Todas las subredes deben ser sub-bloques estrictos del CIDR base.
Sección 11 — Evaluación

Pregunta Tipo Examen AWS

Pon a prueba tu aprendizaje con este escenario de certificación

Una empresa está configurando una nueva VPC con el bloque CIDR 10.0.0.0/16 y crea una subred con el bloque 10.0.1.0/24. ¿Cuántas direcciones IP estarán verdaderamente **disponibles para asignar a instancias EC2** dentro de esta subred?

A) 256 IPs
B) 254 IPs
C) 251 IPs
D) 250 IPs
¡Correcto! (Opción C)
Un bloque /24 contiene 2^8 = 256 direcciones en total. Sin embargo, AWS reserva automáticamente 5 direcciones IP en cada subred para fines de gestión interna de red, dejando 251 IPs disponibles para recursos del usuario.
