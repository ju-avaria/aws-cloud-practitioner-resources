Módulo 1: Calculadora Binario a Decimal (8 bits)

Concepto clave: En informática, un bit es la unidad mínima de información (0 o 1). Un grupo de 8 bits forma un octeto (o byte). Cada posición del bit tiene un valor numérico basado en potencias de 2 ($2^0$ a $2^7$). Haz clic en los interruptores para activar (1) o desactivar (0) cada bit.
Representación Binaria (8 bits)
00000000
Operación Matemática
0 = 0
Resultado Decimal
0

Módulo 2: Construcción de una Dirección IPv4 (32 bits)

Concepto clave: Una dirección IPv4 consta de 32 bits en total, estructurados en 4 octetos (4 × 8 bits = 32 bits) separados por puntos. Dado que cada octeto tiene 8 bits, su rango decimal va de 0 a 255.
Dirección IPv4 Completa en Decimal
192.168.1.10
11000000.16800000.00000001.00001010

Módulo 3: Calculadora CIDR (/0 a /32)

Concepto clave: La notación CIDR (Classless Inter-Domain Routing) indica cuántos bits (de los 32 totales) pertenecen a la Red (Network) usando una barra previa (ej. /24). Los bits restantes pertenecen a los Hosts.

Módulo 4: Calculadora y Desglose para AWS VPC

Regla Crítica de Examen AWS Cloud Practitioner:
En redes tradicionales, se descuentan 2 direcciones por subred (Red y Broadcast).
¡En Amazon VPC se reservan SIEMPRE 5 direcciones IPv4 por subred!

Las 5 IPs reservadas por AWS en cada Subred

x.x.x.0 Dirección de Red: Identificador base de la subred.
x.x.x.1 Router VPC: Reservado para el gateway por defecto.
x.x.x.2 Servidor DNS: Resolutor DNS provisto por AWS.
x.x.x.3 Uso futuro: Reservado por AWS para expansión interna.
x.x.x.255 Broadcast: Última IP de la subred (AWS no soporta broadcast pero la reserva).
