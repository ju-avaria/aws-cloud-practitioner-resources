01 • Fundamentos Conceptuales

¿Cómo se relacionan IA, Machine Learning e IA Generativa?

Piensa en ellos como círculos concéntricos: cada nivel es una especialización más avanzada del anterior.

Inteligencia Artificial (IA) El campo general

Sistemas capaces de realizar tareas que normalmente requieren inteligencia humana (razonar, ver, escuchar, decidir).

Machine Learning (ML) Subconjunto de la IA

Algoritmos que aprenden patrones a partir de datos históricos para hacer predicciones sin ser programados regla por regla.

IA Generativa (GenAI) Subconjunto del ML

Modelos entrenados con enormes volúmenes de datos capaces de crear contenido nuevo: texto, código, imágenes o audio.

IA Tradicional → Automatiza decisiones

Ejemplo: Un sistema basado en reglas o reconocimiento básico que clasifica correos como spam.

Machine Learning → Predice y clasifica

Ejemplo: Predecir la demanda de inventario del próximo mes analizando ventas de los últimos 3 años.

IA Generativa → Crea contenido original

Ejemplo: Redactar respuestas personalizadas de atención al cliente o resumir contratos extensos en segundos.

02 • IA Generativa en AWS (Alta relevancia CLF-C02)

Modelos Fundacionales y Amazon Bedrock

AWS permite construir aplicaciones de IA Generativa sin gestionar servidores ni entrenar modelos desde cero.

Concepto Base

Modelos Fundacionales (FM)

Son modelos de Machine Learning preentrenados con cantidades masivas de datos variados.

A diferencia de los modelos tradicionales de una sola tarea, un mismo modelo fundacional puede resumir, traducir, redactar, programar o responder preguntas.

Ventaja clave: No necesitas recolectar millones de datos ni comprar costosas GPUs para entrenarlos desde cero.
Servicio Administrado (Serverless)

Amazon Bedrock

Servicio totalmente administrado que ofrece acceso mediante API a modelos fundacionales líderes (como Anthropic Claude, Amazon Titan, Meta Llama, entre otros).

Permite personalizar modelos de forma privada con los datos propios de la empresa sin que salgan del entorno seguro de AWS.

Caso práctico: Una aerolínea crea un asistente virtual que consulta sus políticas internas para responder dudas complejas de pasajeros.
★
Clave de examen CLF-C02: Si la pregunta menciona "IA generativa", "modelos fundacionales (FM)" o "crear aplicaciones generativas sin administrar infraestructura", la respuesta es Amazon Bedrock.
03 • Ciclo de Vida de Machine Learning

Amazon SageMaker AI vs. Amazon Bedrock

Una de las distinciones más importantes del examen es saber cuándo usar modelos listos y cuándo construir modelos propios.

Plataforma Completa de ML

¿Qué es Amazon SageMaker AI?

Es un servicio administrado diseñado para que científicos de datos y desarrolladores puedan preparar datos, construir, entrenar y desplegar (implementar) sus propios modelos de Machine Learning a escala. Ejemplo empresarial: Un banco entrena un modelo propio con su historial de transacciones para detectar fraudes en tarjetas de crédito.

Criterio Amazon Bedrock Amazon SageMaker AI
Enfoque principal Consumir y adaptar Modelos Fundacionales ya entrenados para IA Generativa. Construir, entrenar y desplegar modelos de Machine Learning personalizados.
Nivel de gestión Serverless (sin administrar infraestructura de modelos). Control completo sobre algoritmos, entrenamiento y despliegue.
Palabras clave examen IA generativa Modelos fundacionales Construir, entrenar y desplegar modelos ML
04 • Servicios de IA Preentrenados (Visión y Documentos)

Análisis de Imágenes, Video y Documentos

Servicios listos para usar mediante API sin necesidad de saber Machine Learning.

Visión Artificial

Amazon Rekognition

Analiza imágenes y videos para identificar objetos, personas, escenas, actividades, contenido inapropiado y realizar comparación facial.

EntradaFoto / Video
→
SalidaRostros, objetos, moderación
Caso de uso: Verificar la identidad de un usuario comparando su selfie con la foto de su documento o moderar fotos subidas a una red social.
Extracción Inteligente de Documentos

Amazon Textract

Extrae automáticamente texto impreso, escritura a mano, formularios (clave-valor) y tablas desde documentos escaneados o PDFs, superando al OCR tradicional.

EntradaFactura / PDF escaneado
→
SalidaTablas y campos estructurados
Caso de uso: Digitalizar miles de facturas, formularios médicos o solicitudes de préstamos para cargar sus datos en una base de datos.
⚠
No los confundas: ¿Identificar personas/objetos en fotos o videos? → Rekognition. ¿Extraer datos de formularios, tablas o PDFs escaneados? → Textract.
05 • Procesamiento del Lenguaje Natural (NLP)

Comprender, Conversar y Traducir Texto

Tres servicios especializados según el problema que la empresa necesite resolver con el lenguaje humano.

Análisis de Texto

Amazon Comprehend

Problema que resuelve: Descubre información oculta dentro de textos no estructurados.

Detecta sentimientos (positivo, negativo, neutro), idioma, frases clave, entidades (marcas, lugares) y datos personales (PII).

Ejemplo: Analizar 50.000 reseñas de clientes para saber si están satisfechos o molestos con un producto.
Interfaces Conversacionales

Amazon Lex

Problema que resuelve: Automatizar conversaciones con usuarios mediante voz o texto.

Permite construir chatbots y asistentes virtuales que comprenden la intención del usuario (misma tecnología detrás de Alexa).

Ejemplo: Un chatbot bancario en la web o teléfono que permite consultar saldo o agendar citas sin agentes humanos.
Traducción Neuronal

Amazon Translate

Problema que resuelve: Romper barreras idiomáticas en aplicaciones globales.

Ofrece traducción automática rápida, natural y de alta calidad entre decenas de idiomas en tiempo real o por lotes.

Ejemplo: Traducir automáticamente tickets de soporte técnico o descripciones de productos para clientes internacionales.
06 • Servicios de Audio y Voz

Texto a Voz vs. Voz a Texto

Dos servicios complementarios que operan en direcciones exactamente opuestas.

Text-to-Speech (TTS)

Amazon Polly

Convierte texto escrito en voz humana realista (audio sintetizado) en múltiples idiomas y tonos de voz.

EntradaTexto escrito
→
SalidaAudio / Voz natural
Caso de uso: Crear audiolibros a partir de artículos digitales o dar voz a mensajes de respuesta telefónica automática.
Speech-to-Text (ASR)

Amazon Transcribe

Convierte audio o voz hablada en texto escrito de forma automática, identificando incluso distintos interlocutores.

EntradaAudio / Grabación
→
SalidaTexto transcrito
Caso de uso: Generar subtítulos automáticos para videos o transcribir llamadas de un call center para auditar calidad.
💡
Regla mnemotécnica: Polly Parla (habla: Texto → Voz). Transcribe escribe lo que escucha (Voz → Texto).
