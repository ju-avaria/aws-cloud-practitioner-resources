Ejemplo Boto3

Consultando infraestructura mediante código

Lectura de Código 
import boto3

s3 = boto3.client("s3")
response = s3.list_buckets()

for bucket in response["Buckets"]:
    print(bucket["Name"])

Python + AWS Lambda

Ejecución de código Serverless

Serverless
⚡ Evento
→
⚙️ AWS Lambda
→
🐍 Código Python
→
🎯 Acción

Flujo Serverless:

Un archivo llega a Amazon S3 → Se dispara un evento → AWS Lambda ejecuta un script de Python que procesa el archivo automáticamente.

Concepto de examen: AWS Lambda permite ejecutar código sin aprovisionar ni administrar servidores.

Caso de Uso

Procesamiento automatizado en S3

Caso Práctico

Problema Manual:

Una empresa recibe archivos en S3 diariamente. Un empleado debe descargarlos y procesarlos manualmente.

Solución Automatizada:

S3 → Evento → Lambda → Python → Procesamiento instantáneo sin intervención humana.
