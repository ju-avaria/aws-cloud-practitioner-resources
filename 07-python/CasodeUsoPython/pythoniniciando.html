Herramienta 1

Variables: Cajas de Memoria

Una variable es simplemente un nombre o etiqueta que le asignamos a un dato guardado en la memoria para usarlo después.

# Guardando diferentes tipos de datos
severity = "ERROR"
error_count = 3
system_active = True

Las variables pueden guardar texto (cadenas), números enteros, decimales o estados verdaderos/falsos (booleanos).

Representación en Memoria

severity "ERROR"
error_count 3

Pregunta rápida: ¿Qué valor exacto guarda la variable error_count?

Herramienta 2

Tomar Decisiones (if)

La instrucción if permite evaluar una condición. Si la condición se cumple (es Verdadera), Python ejecuta las líneas de código indicadas.

severity = "ERROR"
if severity == "ERROR":
print("⚠️ Se encontró un error")
REGLA DE ORO: Indentación

La sangría (espacios a la izquierda) le indica a Python qué instrucciones pertenecen al bloque de la decisión.

Herramienta 3

Repetición de Tareas (for)

Cuando tenemos listas con cientos de datos, la instrucción for nos permite procesar cada elemento, uno por uno, de forma automatizada.

errors = ["Database", "API", "Storage"]
# Recorre cada elemento de la lista
for error in errors:
print("Revisando módulo:", error)

Estructura de Datos 1

Listas: Colecciones Ordenadas

Una Lista es un contenedor agrupado que guarda múltiples elementos en un orden específico. Se define utilizando corchetes [ ].

errors = [ "Database", "API", "Database" ]

Es perfecta para acumular líneas de registros que leemos desde un archivo de logs.

Inspeccionando la Lista

Posición [0] "Database"
Posición [1] "API"
Posición [2] "Database"

Pregunta: ¿Cuántos elementos totales contiene esta lista?

Estructura de Datos 2

Diccionarios: Parejas Clave ➔ Valor

Un Diccionario permite asociar una Clave con un Valor. Se define con llaves { }.

error_count = { "Database": 2, "API": 1 }

Ideal para resúmenes y contadores (ej. "¿Cuántos fallos registró cada servicio de la app?").

Estructura Clave ➔ Valor

Clave (Módulo) Valor (Conteo)
"Database" 2
"API" 1

Reto: Si aparece un nuevo error de "Database", ¿cuál debería ser su nuevo valor?

Herramienta 4

Funciones: Bloques Reutilizables

Una Función es un bloque de código organizativo que realiza una tarea específica y puede ser reutilizado múltiples veces.

Entrada

Lista de Datos

➔
Procesamiento

FUNCIÓN

count_errors()
➔
Resultado

Total / Informe

¿Por qué usar Funciones?

  • Evitan repetir la misma lógica en diferentes partes del programa.
  • Permiten dividir un problema complejo en tareas pequeñas.
  • Hacen que el código sea fácil de leer, mantener y probar.
