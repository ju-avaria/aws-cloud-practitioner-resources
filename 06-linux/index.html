¿Por qué Linux es importante en AWS?

AWS es la plataforma de servicios[cite: 1, 2]. EC2 proporciona el cómputo virtual[cite: 1, 2]. Linux es el sistema operativo invitado que ejecuta la aplicación[cite: 1, 2].

Ejemplo: Al desplegar una web en AWS, creas un servidor virtual (EC2), eliges Linux como sistema operativo e instalas Apache/Nginx para servidor web[cite: 1, 2].

Usuarios y Permisos

El modelo de permisos POSIX define tres clases de usuarios:

Propietario (u)

El usuario dueño del archivo.

Grupo (g)

Grupo de usuarios con acceso asignado.

Otros (o)

Todos los demás usuarios del sistema.

r = Read (Lectura)
w = Write (Escritura)
x = Execute (Ejecución)

¿Cómo interpretamos los permisos?

-rwxr-xr--

Usuario (u)

rwx: Lectura, Escritura y Ejecución permitidas.

Grupo (g)

r-x: Lectura y Ejecución permitidas (sin escritura).

Otros (o)

r--: Solo Lectura permitida.

Comandos conceptuales clave: chmod (cambia permisos) y chown (cambia propietario)[cite: 1, 2, 4].

"Intento conectarme por SSH pero la conexión no responde (Timeout). ¿Qué debería revisar primero?"

Debes revisar las Inbound Rules (Reglas de Entrada) del Security Group asociado a la instancia EC2 para confirmar que el tráfico en el Puerto 22 (SSH) está permitido desde tu dirección IP[cite: 1, 2].

Modelo de Responsabilidad Compartida

Responsabilidad de AWS

Seguridad DE la Nube:

  • Hardware e infraestructura física.
  • Centros de datos y red global.
  • Software del hipervisor (Nitro/KVM).

Responsabilidad del Cliente

Seguridad EN la Nube (en EC2):

  • Sistema Operativo invitado (actualizaciones/parches).
  • Configuración de Firewall (Security Group).
  • Aplicaciones e instalación de código.
  • Datos e identidades (IAM).

Mini Examen Cloud Practitioner (1/4)

1. Un cliente ejecuta una aplicación web en una instancia Amazon EC2 con Amazon Linux 2023. Según el Modelo de Responsabilidad Compartida de AWS, ¿cuál es una responsabilidad del cliente?
Respuesta Correcta: C. En Amazon EC2, el cliente es responsable de gestionar y parchear el sistema operativo invitado, las aplicaciones y la configuración del firewall (Security Group)[cite: 1, 2]. AWS se encarga de la infraestructura física e hipervisor[cite: 1, 2].

Mini Examen Cloud Practitioner (2/4)

2. ¿Qué componente de AWS funciona como un firewall virtual para controlar el tráfico entrante a una instancia Linux en el Puerto 22 (SSH)?
Respuesta Correcta: B. Un Security Group actúa como un firewall virtual para las instancias EC2, controlando el tráfico permitido de entrada y salida[cite: 1, 2].

Mini Examen Cloud Practitioner (3/4)

3. ¿Qué es Amazon Linux 2023 en el contexto de AWS?
Respuesta Correcta: B. Amazon Linux es una distribución Linux mantenida directamente por AWS, optimizada para la nube y proporcionada como una AMI[cite: 1, 2].
