LINUX ESENCIAL PARA AWS CLOUD PRACTITIONER

Guía visual rápida para reconocer comandos Linux clave en instancias Amazon EC2

🟢 NIVEL 1 — Empieza por estos

Si estás comenzando con Linux, aprende primero estos comandos esenciales para moverte y gestionar archivos.

pwd | ls | cd | cp | mv | rm | cat | sudo | whoami

🟡 NIVEL 2 — Especialmente útiles en EC2

Comandos clave para diagnóstico y control de servicios, red, procesos y paquetes en instancias cloud.

systemctl | ip | ss | curl | tail | ps | top | dnf

🔵 NIVEL 3 — Conviene reconocerlos

No necesitas dominarlos todavía; basta con entender para qué sirven al investigar o ajustar permisos.

grep | find | head | less | history | chmod | chown
SECCIÓN 1 — ¿Por qué Linux importa en AWS?
AWS → EC2 → Instancia virtual → Sistema operativo Linux → Terminal → Comandos

EC2 puede ejecutar sistemas operativos Linux. Los comandos permiten administrar lo que ocurre dentro de la instancia.

DENTRO DE EC2 (Linux administra):

archivos · procesos · servicios · usuarios · paquetes · configuración del sistema.

AWS (Proporciona alrededor):

infraestructura · red · almacenamiento · identidad y permisos · seguridad a nivel de servicio.

SECCIÓN 2 — Navegar por el sistema 🟢 Nivel 1
pwd ¿Dónde estoy? Muestra el directorio actual.
ls ¿Qué hay aquí? Lista archivos y carpetas.
ls -la ¿Qué hay, con ocultos? Muestra información detallada.
cd carpeta Entrar a carpeta Cambia al directorio especificado.
cd .. Subir un nivel Regresa al directorio padre.
clear Limpiar pantalla Limpia la terminal.
$ pwd /home/ec2-user
SECCIÓN 3 — Archivos y carpetas 🟢 Nivel 1
mkdir carpeta Crear carpeta.
touch archivo.txt Crear archivo vacío.
cp archivo destino Copiar.
mv archivo destino Mover o renombrar.
rm archivo Eliminar archivo.
rm -r carpeta Eliminar carpeta y contenido.
⚠️ rm elimina archivos. No existe una papelera tradicional en la terminal.
SECCIÓN 4 — Leer archivos 🟢 Nivel 1
cat archivo.txt Leer rápidamente un archivo.
less archivo.txt Revisar archivos largos pautadamente.
head archivo.txt Ver las primeras líneas.
tail archivo.txt Ver las últimas líneas.
tail -f archivo.log Seguir un archivo de logs en tiempo real.
$ tail -f application.log

💡 Los logs ayudan a investigar qué está ocurriendo en una aplicación o servidor.

SECCIÓN 5 — Usuario y privilegios 🟢 Nivel 1
whoami ¿Quién soy? Muestra el usuario actual.
id ¿Qué grupos tengo? Muestra ID de usuario y grupos.
sudo comando Ejecutar con privilegios Ejecuta un comando con privilegios elevados.
$ whoami ec2-user $ sudo systemctl status httpd
sudo ≠ ser root permanentemente. Permite ejecutar comandos determinados con elevación.
SECCIÓN 6 — Servicios en EC2 🟡 Nivel 2 ¿Está funcionando mi servidor?
systemctl status servicio Consultar estado del servicio.
systemctl start servicio Iniciar servicio.
systemctl stop servicio Detener servicio.
systemctl restart servicio Reiniciar servicio.
EC2 → Linux → systemd → httpd → Servidor web

systemctl permite administrar servicios del sistema en distribuciones modernas.

SECCIÓN 7 — Procesos y recursos 🟡 Nivel 2
ps Ver procesos activos en la sesión.
ps aux Ver todos los procesos con información detallada.
top Observar procesos y consumo de CPU/RAM en tiempo real.
CPU / RAM → Procesos → top

💡 Útil para investigar qué está consumiendo recursos dentro de una instancia.

SECCIÓN 8 — Red en EC2 🟡 Nivel 2 ¿Qué pasa con la red?
ip addrVer interfaces e IP en Linux.
hostnameVer el nombre del host.
ping hostProbar conectividad.
curl URLRealizar solicitud HTTP.
ss -tulnVer puertos en escucha.
EC2 → Interfaz → IP → Puerto → Servicio
⚠️ Linux ≠ toda la red de AWS. Linux consulta la red interna. AWS controla externamente con VPC, Security Groups y NACLs
SECCIÓN 9 — Instalar software 🟡 Nivel 2 ¿Necesito instalar un programa?
dnf install paquete Instalar paquetes en Amazon Linux moderno (AL2023)
dnf update Actualizar paquetes instalados
yum install paquete Comando en sistemas Amazon Linux anteriores o tutoriales
$ sudo dnf install httpd
DNF ↓ Instala Apache ↓ httpd ↓ systemctl ↓ Servidor web
SECCIÓN 10 — Buscar información 🔵 Nivel 3
grep palabra archivo Buscar texto dentro de un archivo
find ruta -name archivo Buscar archivos por nombre
history Ver comandos ejecutados anteriormente
less archivo Revisar información extensa ordenadamente
$ grep ERROR application.log

💡 Estos comandos ayudan a investigar archivos y resultados sin editar el contenido.

SECCIÓN 12 — Mini Desafío EC2: "Tienes una EC2 con Apache. ¿Qué haces?"
1 ¿Dónde estoy?
pwd
2 ¿Quién soy?
whoami
3 ¿Qué archivos existen?
ls -la
4 ¿Apache está funcionando?
sudo systemctl status httpd
5 ¿Qué puertos están escuchando?
ss -tuln
6 ¿El servidor responde?
curl localhost
7 ¿Qué dicen los logs?

"No memorices comandos aislados. Piensa primero qué necesitas comprobar y después elige el comando."
