Bases de Datos Relacionales (SQL)

Estructura rígida organizada en Tablas, Filas y Columnas con relaciones mediante SQL

Características clave:
  • Esquema estricto y predefinido.
  • Integridad de datos (Propiedades ACID).
  • Consultas complejas mediante SQL.
  • Ideal para sistemas transaccionales (ERP, CRM, Banca).
ID Nombre Email
1 Ana Gómez ana@email.com
2 Juan Pérez juan@email.com
🎯 Clave de Examen Si la pregunta menciona "estructurado", "SQL", "transacciones financieras" o "relaciones complejas", piensa en una solución Relacional.

Bases de Datos NoSQL

Esquema flexible diseñado para gran escala, baja latencia y alta concurrencia

Características clave:
  • Esquema dinámico (Key-Value, Documentos).
  • Escalabilidad horizontal masiva.
  • Mantenimiento de baja latencia a cualquier escala.
  • Sin uniones (JOINs) complejas de SQL.
// Documento JSON / Key-Value { "id": 101, "nombre": "Juan", "productos": [ "Laptop", "Mouse" ], "activo": true }
💡 Nota Pedagógica: NoSQL no reemplaza a SQL ni es "mejor". Es simplemente la herramienta correcta para patrones de acceso sin esquema fijo o que requieren latencias de milisegundos de un solo dígito a escala masiva.

Comparación: Relacional vs NoSQL

¿Cuál elegirías? Evalúa el patrón antes de seleccionar la tecnología

Característica Relacional (SQL) NoSQL
Estructura Tablas, filas y columnas fijas Llave-Valor, Documentos JSON
Esquema Rígido / Predefinido Flexible / Dinámico
Escalabilidad Principalmente Vertical (Cómputo) Horizontal (Particionado fácil)
Uso Típico ERP, Contabilidad, Pedidos Catálogos, Redes Sociales, IoT

Amazon RDS

Relational Database Service = Base de datos relacional administrada por AWS

Aplicación
➔
Amazon RDS
➔
DB Relacional
🛠️ Simplificación
AWS aprovisiona el hardware, instala el motor y aplica parches del sistema operativo.
💾 Respaldos
Backups automáticos configurables y snapshots bajo demanda.

Opción Multi-AZ para redundancia y failover automático ante fallas.
🎯 Clave de Examen Amazon RDS quita la carga operativa de administrar el sistema operativo y parches del servidor de la base de datos relacional.

Amazon Aurora

Base de datos relacional de clase empresarial desarrollada por AWS, compatible con MySQL y PostgreSQL

⚡ Rendimiento
Hasta 5x más rápida que MySQL estándar y 3x más que PostgreSQL.
🛡️ Resiliencia
Guarda 6 copias de tus datos en 3 Zonas de Disponibilidad (AZs).
📈 Auto-escalado
El almacenamiento crece automáticamente según la necesidad (hasta 128 TiB).

Amazon Redshift

Servicio de Data Warehouse petabyte-scale para análisis de grandes volúmenes de datos (OLAP)

🔄 DB Operacional (RDS / DynamoDB)
Optimizada para transacciones rápidas e individuales (OLTP). Registrar compras actuales.
📊 Data Warehouse (Redshift)
Optimizado para consultas complejas sobre años de datos analíticos (OLAP). Generar reportes de negocio.
💼 Caso de Negocio: Una tienda analiza 10 años de ventas históricas para proyectar tendencias de mercado sin ralentizar la base de datos de compras del día a día.
🎯 Clave de Examen Redshift ≠ RDS. Redshift es para Analytics / Business Intelligence / Data Warehouse.
