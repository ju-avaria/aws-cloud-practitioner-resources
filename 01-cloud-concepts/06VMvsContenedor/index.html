Sección 01 — Introducción

Máquinas Virtuales vs. Contenedores

¿Cómo podemos ejecutar varias aplicaciones aisladas sobre el mismo servidor físico?

🖥️ Máquina Virtual (VM)

Virtualización a nivel de hardware. Cada aplicación corre sobre su propio Sistema Operativo Invitado completo.

📦 Contenedor

Virtualización a nivel de Sistema Operativo. Las aplicaciones comparten el mismo Kernel del Host de forma aislada.

Sección 04 — Arquitectura Contenedores

¿Qué es un Contenedor?

Los contenedores empaquetan la Aplicación + Dependencias compartiendo el Kernel del Host

Container A
App A + Dep
Container B
App B + Dep
Container C
App C + Dep
Container Runtime (Docker / containerd)
Host Operating System (Kernel Linux / Windows)
Physical Hardware
👈 Haz clic en los componentes

A diferencia de las VMs, NO hay un Guest OS duplicado en cada contenedor. Todos se comunican directamente con el Kernel del Host.

Sección 10 — AWS Cloud Practitioner

Máquinas Virtuales en AWS: Amazon EC2

Amazon Elastic Compute Cloud es el servicio fundamental de IaaS en AWS

☁️ Amazon EC2 (Elastic Compute Cloud)

Instancias de cómputo virtualizadas bajo demanda en la nube de AWS. Equivalente directo a una Máquina Virtual en tu centro de datos.

🧩 Componentes Clave de EC2
  • AMI: Plantilla con el Sistema Operativo e imagen base.
  • Instance Type: Tamaño de CPU, RAM y Red.
  • EBS: Disco duro virtual persistentemente adjunto.
  • Security Group: Firewall virtual a nivel de instancia.
Jerarquía de Despliegue AWS
Región AWS (Ej. us-east-1)
Availability Zone (AZ)

Sección 11 — AWS Cloud Practitioner

Ecosistema de Contenedores en AWS

Servicios clave para gestionar, almacenar y ejecutar contenedores

📦 Amazon ECS

Elastic Container Service: Orquestador altamente escalable para ejecutar contenedores Docker en AWS.

Task: Definición del contenedor.
Service: Mantiene réplicas activas.
Cluster: Grupo de cómputo.
🗄️ Amazon ECR

Elastic Container Registry: Registro gestionado para almacenar y recuperar imágenes Docker de forma segura.

⚡ AWS Fargate

Motor de cómputo Serverless para contenedores. Ejecuta contenedores sin gestionar ni aprovisionar servidores EC2.

Sección 13 — Relación Tecnológica

¿VMs o Contenedores? ¡Ambos Juntos!

Evita el error común: "Es una u otra, nunca ambas"

🤝 Arquitectura Híbrida Real

En la gran mayoría de despliegues en la nube (como ECS sobre EC2 o Kubernetes en EC2), los contenedores se ejecutan DENTRO de Máquinas Virtuales.

  • La VM provee aislamiento fuerte de infraestructura y límites de red.
  • Los contenedores proveen velocidad de despliegue y empaquetado de aplicaciones.
