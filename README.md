# AWS Cloud Practitioner Resources

Repositorio de material de estudio para la preparación del examen **AWS Certified Cloud Practitioner**.

Este proyecto reúne recursos organizados para facilitar el aprendizaje progresivo de los principales conceptos, servicios y fundamentos de AWS necesarios para comprender la nube y prepararse para la certificación.

> **Objetivo:** aprender los conceptos fundamentales de AWS, comprender cuándo utilizar sus principales servicios y desarrollar una base sólida para continuar posteriormente con certificaciones y contenidos más avanzados.

---

## 🎯 Enfoque de aprendizaje

El objetivo no es únicamente memorizar nombres de servicios.

Los materiales buscan ayudar a comprender:

* **Qué es** un servicio.
* **Para qué sirve**.
* **Qué problema resuelve**.
* **Cuándo utilizarlo**.
* **Cuándo no utilizarlo**.
* **Cómo diferenciarlo de servicios similares**.
* **Cómo reconocerlo en preguntas del examen**.

Cuando sea apropiado, los contenidos incluirán ejemplos y casos de uso para relacionar los conceptos con situaciones reales.
