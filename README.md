# AWS Cloud Practitioner Resources

Repositorio educativo de recursos de estudio para aprender **AWS, Cloud Computing y fundamentos tecnológicos relacionados**, con un enfoque inicial en la preparación para la certificación **AWS Certified Cloud Practitioner**.

El proyecto está pensado para avanzar progresivamente desde los conceptos fundamentales hasta la comprensión de servicios, seguridad, costos y arquitectura de AWS.

---

## 🎯 Objetivo

Construir una base sólida para comprender:

* Qué es Cloud Computing.
* Cómo funciona AWS.
* Qué problemas resuelven sus principales servicios.
* Cuándo utilizar determinados servicios.
* Cómo funcionan los fundamentos de redes, sistemas y bases de datos.
* Cómo aplicar conceptos de seguridad, costos y arquitectura.
* Cómo prepararse progresivamente para certificaciones AWS.

El objetivo no es solamente memorizar nombres de servicios, sino **comprender los conceptos y relacionarlos con situaciones reales**.

# 🧭 Enfoque de aprendizaje

El material busca responder cinco preguntas fundamentales:

> **¿Qué es?**
> **¿Para qué sirve?**
> **¿Qué problema resuelve?**
> **¿Cuándo lo utilizaría?**
> **¿Cómo lo diferencio de otras alternativas?**

Cuando sea apropiado, los contenidos podrán incluir:

* Explicaciones conceptuales.
* Ejemplos.
* Casos de uso.
* Comparaciones entre servicios.
* Diagramas.
* Preguntas de práctica.
* Palabras clave para el examen.
* Referencias a documentación oficial.
